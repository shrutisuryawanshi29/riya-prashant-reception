# Riya & Prashant — Reception Invitation

An independent reception-only storybook, using the shared visual design and assets of our wedding invitation.

## Development

Run `npm ci`, then `npm run dev`. Run `npm run build` for a production build.

Set `VITE_SITE_URL` to the final public HTTPS URL in the hosting project to enable canonical sharing metadata, social preview, and sharing actions. Leave it unset until the actual URL is known. Do not use the wedding invitation's Vercel project or URL.
